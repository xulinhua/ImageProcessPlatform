# 通讯调试器

设备通道的收发窗口。直接调用 `CommMgr`，不进方案台账，也不跑工站。串口、网口、HTTP、WebSocket 和 Modbus 主站都可以在这里对一下。

界面样式在本工程的 `debug_theme.h`，不和进程通讯调试器共用。程序图标是 Lucide 的 cable（ISC），一根线缆，表示设备通道。一次只打开一条通道。

## 编译

在 `VisionPlatform.sln` 的 **ClassLib / Port** 里生成 `Vision.PortDebug`。配置 **Debug|x64** 或 **Release|x64**。产出 `bin/<平台>/<配置>/Vision.PortDebug.exe`，和 `VisionPort.dll`、`VisionCommon.dll` 在同一目录。需要本机 Qt 5.15.2，环境变量 `QTDIR` 指向对应套件。

## 使用

菜单栏有文件、编辑、查看、帮助。页签决定通道类型，打开后页签锁住。接收区有 HEX、时间戳和暂停显示，报文用「发→」「收←」区分方向。日志单独一块，记打开、关闭、发送字节数和失败原因。状态栏左边是连接状态，右边累计收发字节和帧数。

字节通道和 WebSocket 的发送可以加回车换行、解析 `\r \n \t \0 \xHH`、按 UTF-8 或 GBK 编码，并在末尾加累加和、异或或 Modbus CRC16。HEX 可以写成 `01 03` 或 `0103`。Ctrl+Enter 发送当前内容。历史发送和下面六条指令会记在本机，多条可以按间隔循环。清空只清屏幕。

| 页 | 打开后做什么 |
|---|---|
| 串口 | 选端口、波特率、数据位、校验、停止位，收发原始字节 |
| TCP 客户端 | 填主机和端口 |
| TCP 服务端 | 填监听端口。右侧列出已接入的客户端，发送前先选一个 |
| UDP | 本机端口、目标主机和目标端口 |
| HTTP | 填 URL。发送区有方法、请求头和请求体。`Content-Type` 和 `Authorization: Bearer` 会随请求发出，接收区显示状态码和正文 |
| WebSocket | 填 URL 后打开即连接。不勾 HEX 时发文本帧。断开关掉这条连接 |
| Modbus RTU / TCP | 主站。读保持寄存器、读输入寄存器、写单寄存器、写多寄存器。接收区显示寄存器值，原始字节区可折叠，里面是发出和收到的整帧 |

打开失败时，状态和接收区都显示 `CommMgr` 返回的原因。收包在工作线程里完成，界面定时把已经拷好的行追加到接收框。
