# 绘制与屏蔽方案

约束：只改 `HsImageCtrl` 的交互。不改 `HsCommData` 的几何种类，不给 `HsRegion` 加并集和差集，不把 `KindMask` 做成画笔。现有 `setDrawTool` 非模态保留。算法线程不进入绘制。不把画布收进模态对话框。

## 1. 结论

两件事分开做，都落在 `HsImageWindow` 上。`ImageWidgetApi` 只转发，不另做一套信号。

第一件是绘制会话。圆、矩形、椭圆、直线、十字、折线、多边形不加新几何，只在现有鼠标状态机上加一次独占。一次会话一条结果，结束回到浏览。调用方接 `drawSessionFinished`，函数本身不阻塞。

第二件是屏蔽涂抹。新工具 `ToolBrush`，只能在会话里用。编辑过程放在控件内部、与底图同大的二值缓冲。左键涂，右键擦。确定时把非 0 像素扫成 `HsRegion`，当作一条普通 Drawing ROI 提交。取消丢掉缓冲。

`setDrawTool` 继续给设计器和 Demo 连画。两种模式并存，和 Halcon 同时有 `draw_*` 与 Drawing Object 是同一件事。

## 2. 现在缺什么

已经有的：

- `DrawTool`：浏览、圆、轴对齐矩形、旋转矩形、椭圆、直线、十字、折线、多边形、文本。
- 圆和矩形按下拖动，松开发 `roiCommitted`，工具不收回。
- 多边形、折线用右键或 Enter 结束，Esc 取消，Backspace 退点。
- 滚轮缩放、中键平移在绘制中可用。
- `HsRegion` 能由矩形或闭合多边形生成行程。`KindMask` 能显示整幅 8bit 灰度。
- 设计态可画，运行态强制浏览并藏起 Drawing 层。

对不上的是独占和涂抹。

`mousePressEvent` 里 `tryBeginEdit` 先于落笔。绘制中仍能点中已有 ROI、拖手柄、点 Stack。双击会取消橡皮筋并 `fitToWindow`。右键还能弹出快照菜单（多边形绘制中除外）。工具一旦 `setDrawTool` 就一直有效，调用方不等结果。

没有画笔，没有半径，没有擦除。`HsRegion` 没有并、差、膨胀，不能在鼠标移动时做行程并集。`KindMask` 的绘制每次重铺整幅 ARGB，不能跟手涂。Demo 里的掩膜是写死的结果叠加，不是交互工具。

## 3. 市面怎么做

对照的是绘制时窗口听谁的，以及屏蔽最后存成什么。不是某一个 SDK 的类名。

**Halcon `draw_*`。** `draw_circle`、`draw_rectangle1` 阻塞到这一笔结束，返回后算子退出，不会连画。`draw_polygon` 用右键闭合。`draw_region` 按住左键用 `set_paint` 传入的区域当章往上盖，右键结束，结果是 Region 行程，不是整幅灰度图。缩放在绘制中仍可用。

**Halcon Drawing Object。** 图元挂在窗口上，回调通知拖动，不阻塞。这就是现在的 `setDrawTool` 加 `roiCommitted`。

**海康 VisionMaster 一类。** 点绘制进入独占，确定或取消才离开。掩膜有圆画笔和橡皮擦，半径可调，可以自由涂抹。结果是掩膜图，再交给模块。

**基恩士。** 掩膜在单独一页里画完再确定。有笔宽，有自由涂抹。

**康耐视 VisionPro。** `CogRectangle` 一类挂在显示上，随时可改，更接近现在的非模态。不能当成“工业软件都是模态”的证据。

共识只取这些：形状是一次独占、一次一条；屏蔽是硬边二值、圆画笔、半径按图像像素、左涂右擦、确定才写回。软边、压感、魔棒不取。

## 4. 绘制会话

会话是 `HsImageWindow` 上的一个开关，不是新窗口。

```text
beginDrawSession(tool)
        |
        +-- 失败：运行态、已有会话、无底图、工具不在允许列表
        |
        v
独占鼠标
        |
        +-- 形状松开，或折线/多边形右键、Enter
        |         commit 这一条，发 roiCommitted，再发 drawSessionFinished(accepted=true)
        |
        +-- Esc、cancelDrawSession、切到运行态、会话中换底图
                  丢掉预览，不发 roiCommitted，发 drawSessionFinished(accepted=false)
        |
        v
工具回到 ToolBrowse
```

允许进入会话的工具：圆、轴对齐矩形、旋转矩形、椭圆、直线、十字、折线、多边形，以及第 5 节的画笔。`ToolBrowse` 和 `ToolText` 返回失败。文本仍走现在的非模态单击。

会话进行时：

| 操作 | 行为 |
|---|---|
| 点其它 ROI、拖手柄、点 Stack | 不响应 |
| 右键菜单、双击适应窗口 | 不响应。折线和多边形的右键仍是结束 |
| 滚轮缩放、中键平移 | 保留 |
| 左键拖视图 | 不平移。左键只用于这一笔 |
| `setDrawTool` | 忽略，不换工具，也不结束会话 |
| 已有 Drawing | 留在画面上，不清空。会话只追加这一条，或什么都不加 |

形状还没落下第一点时，`commitDrawSession` 等于取消。橡皮筋已经在拖，则按当前预览提交；预览过小（现有 `finishPreviewIfTiny`，约 2 像素）等于取消，不留空 ROI。多边形少于 3 点、折线少于 2 点，提交等于取消。

接受时顺序固定：先 `roiCommitted`，再 `drawSessionFinished`。旧的监听不用改。取消时 Drawing 层不留预览，`drawSessionFinished` 的图形 id 为空。

信号只挂在 `HsImageWindow`。壳通过 `ImageWidgetApi::imageWindow()` 连接，和现在的 `roiCommitted` 一样。`ImageWidgetApi` 转发 `beginDrawSession`、`commitDrawSession`、`cancelDrawSession`、`drawSessionActive`。

不在控件里做确定/取消条。壳自己放按钮，按钮调上面两个函数。Demo 用 Enter 提交当前笔、Esc 取消。多边形和折线的 Enter 仍是结束并提交，和现在一致。

## 5. 屏蔽涂抹

`ToolBrush` 不能 `setDrawTool`。非会话调用视为失败，工具保持不变。涂抹没有“松开即结束”的自然边界，必须放在会话里，否则又会变回钉住的工具。

```text
beginDrawSession(ToolBrush)     按当前底图宽高分配二值缓冲，全 0
        |
        +-- 左键按住：涂。右键按住：擦。半径用 setBrushRadius
        |
        +-- Enter 或 commitDrawSession
        |         非 0 像素按行扫成 HsRegion，走第 4 节的接受路径
        |
        +-- Esc、cancelDrawSession、换底图、切运行态
                  丢掉缓冲，走取消路径
```

画笔：

- 半径单位是图像像素，不随缩放变。默认 8，夹在 1 到 256。中心对齐到像素，覆盖半径内的像素（含边界）。
- 移动时沿上一采样点到当前点盖章，步长 `max(1, 半径/3)`。只盖当前点的话，快速拖动会断开。
- 颜色用当前 `drawingStyle` 的 fill。fill 未设则用 stroke，alpha 140。不新加颜色接口。
- 叠加用一块持久的着色缓存，只更新这一笔的脏矩形。不走现在 `KindMask` 每次重铺整幅图的路径。缓冲不写进 `Graphic`，确定之后才出现一条 ROI。

提交出来的图形：`KindObject`，几何是 `HsRegion`，`RoleDrawing`，`frameId` 为当前底图。id 前缀沿用 `roi.region`。缓冲里没有前景像素时等于取消，不提交空区域。

撤销：Ctrl+Z 撤销一整笔（一次按下到松开），不是每次鼠标移动。栈最多 8 份，每份是与图像同大的二值缓冲。500 万像素、8 笔大约 40MB。不做重做。Delete 把缓冲清零并记入撤销，不结束会话。

无底图不能开画笔会话。会话中 `setImage` 换了尺寸或按刷新策略清掉 Drawing，会话直接取消。

## 6. 接口

加在 `HsImageWindowTypes.h`：

```text
ToolBrush    仅绘制会话。圆画笔涂成 HsRegion
```

加在 `HsImageWindow`：

| 接口 | 作用 |
|---|---|
| `beginDrawSession(DrawTool) -> bool` | 开一次独占。失败原因见第 4 节 |
| `drawSessionActive() -> bool` | 是否在会话中 |
| `commitDrawSession()` | 按第 4、5 节提交或当成取消 |
| `cancelDrawSession()` | 同 Esc |
| `setBrushRadius(int)` / `brushRadius()` | 图像像素，夹到 1..256 |
| `drawSessionFinished(Graphic, bool accepted)` | 会话结束。接受时图形就是刚提交的那条 |

`ImageWidgetApi` 转发除信号以外的五个函数。不在壳层类上再声明信号。

不增加 `HsCommData` 类型。不增加 `HsRegion` 的并集、差集。`KindMask` 的字段和绘制路径不动。

## 7. 本期明确不做

- `QEventLoop` 或 `drawModal` 这种阻塞函数。嵌套事件循环会和换图、定时器重入。壳要“画完再继续”，接 `drawSessionFinished`。
- 算法线程、`run()` 里调用绘制。绘制只在界面线程。
- 软边笔刷、压感、魔棒、灰度屏蔽。
- 矩形、多边形当作图章并进同一块缓冲。
- 把已有 `HsRegion` 栅格化后再涂。每次画笔会话从空缓冲开始。改已有 ROI 仍走非模态手柄。
- 非模态 `setDrawTool(ToolBrush)`。
- 控件内嵌确定/取消条。
- 改 `WindowDesign` / `WindowRuntime` 的含义。运行态仍然不能画。
- 改 `VisionPlatform` 的工具壳和 `ToolCaps`。本方案停在图像控件。

## 8. 落地顺序

1. 绘制会话状态机，只接形状和折线、多边形。`HsImageDemo` 加一个按钮：进入会话后只能画一个，松开或右键结束，期间点不中旧 ROI，双击不再适应窗口，Esc 不留预览。`setDrawTool` 的旧路径行为不变。
2. `ImageWidgetApi` 转发会话的四个函数和画笔半径。
3. 画笔缓冲、盖章、擦除、脏矩形叠加、Ctrl+Z、Delete、提交成 `HsRegion`。Demo 用 Enter / Esc 收尾。
4. 第 3 步做完再看要不要把矩形、多边形并进同一缓冲。那是下一期，不在本方案里开接口。

第 1 步做完，模态形状就能用。第 3 步做完，屏蔽涂抹才能用。两步之间不互相堵住。

## 9. 已定

1. 模态是画布会话，不是对话框。`setDrawTool` 非模态保留。
2. 一次会话一条 ROI。接受时先 `roiCommitted`，再 `drawSessionFinished`。取消不留预览。
3. 会话中保留滚轮和中键平移，其余点选、菜单、双击适应窗口关掉。
4. 不阻塞。信号只在 `HsImageWindow` 上。算法线程不绘制。
5. 屏蔽是内部二值缓冲，确定后扫成 `HsRegion`。`KindMask` 仍只做结果叠加。
6. 画笔半径按图像像素，左涂右擦，按笔撤销。`ToolBrush` 只能进会话。
7. 本期不改 `HsCommData`，不改 `VisionPlatform`。
