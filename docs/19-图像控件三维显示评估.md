# 图像控件加三维显示：方案评估

评估日期：2026-10-30。  
对象：`HsImageCtrl` 内二维图像与三维点云如何同区域显示。  
关联：[`17-三维方案.md`](17-三维方案.md)、`HsImageWindow` / `HsImageWindowMenu` / `ImageWidgetApi`。  
显示侧参考：CloudCompare（`ccGLWindow` / `ccPointCloud`）、MeshLab（`GLArea` / trackball）；交互壳参考 Halcon 图形窗「一块区域、模式可切」。  
约束：VS2022（v143）、C++17、Qt 5.15.2、Windows；界面只认 `HsCommData`；不链接 Halcon / PCL / CloudCompare / MeshLab 库。

---

## 1. 结论

| 问题 | 决定 |
|---|---|
| 2D / 3D 关系 | **独立实现**：`HsImageWindow` 与 `HsCloudWindow` 互不继承，协议不混用 |
| 怎么摆 | `HsImageCtrl` 内 **`HsViewShell` 外层壳**，内容区叠放两子窗；**右键菜单切「图像 / 点云」**；不加顶栏、不加浮动条 |
| 3D 怎么画 | 自研 `QOpenGLWidget`；**学 CloudCompare 的点云 VBO / 抽点 / pivot 相机**；交互手感参考 MeshLab trackball；不嵌第三方窗口 |
| 业务改什么 | 只嵌壳、灌 `Cloud3` / `Shape3`；切换与 GL 细节不出 `HsImageCtrl` |
| 图像窗内核 | **不改**成兼画点云 |

**落地顺序**：`HsCloudWindow`（可转）→ `HsViewShell` + 右键切换 → `ImageWidgetApi` 组合壳 → 调试宿主 → 设计态 / 运行格。

## 2. 对标：Halcon / CloudCompare / MeshLab

### 2.1 Halcon（壳与模式）

对齐：一块主视图、2D 与 3D 交互分离、模式可切换。  
切换入口用现网习惯：**右键菜单**，不做浮动工具条。

| 习惯 | 本方案 |
|---|---|
| 单一图形区 | `HsViewShell` 内容区 stack |
| 切 2D / 3D | 右键「切换到点云视图」/「切换到图像视图」 |
| 2D ROI | 仅 `HsImageWindow`；3D 模式不响应绘制会话 |
| 3D 浏览 | 仅 `HsCloudWindow` |

### 2.2 CloudCompare（点云绘制——主参考）

| CC 做法 | 是否采用 | 落到 `HsCloudWindow` |
|---|---|---|
| `QOpenGLWidget` 自管上下文 | 采用 | 基类同 CC |
| `ccHObject` 实体树 + 多文档 | **不采用** | 壳内固定：底云 + 命名额外层 + shapes/poses |
| 点云 chunk + VBO 上传 | 采用（简化） | 一层一个（或少量）VBO；云指针与点数未变不重传 |
| VBO 失败退回客户端数组 | 采用 | 工控机兼容 |
| 拖动时 decim / LOD | 采用（简化） | 固定绘制预算（约 150 万点），步长抽点只进显存，不改 `Cloud3` |
| 绕 pivot 轨道球、仰角夹紧 | 采用 | 与 `Geom3`（Z 朝观察者、Y 上）一致 |
| 延时 / 专用 picking pass | 第一期简化 | 已上传点里做屏幕邻域最近点即可 |
| 立体、FBO 合成、着色器生态 | **不采用** | 第一期固定管线足够 |

### 2.3 MeshLab（交互与多视口——辅参考）

| MeshLab 做法 | 是否采用 | 说明 |
|---|---|---|
| Trackball 旋转 / 缩放 / 平移 | 采用手感 | 左键转、滚轮缩、中键平移；**右键只出菜单**（与图像窗一致，不同于部分 ML 右键习惯） |
| `MLSceneGLSharedDataContext` 多视口共享 GPU | 第一期不采用 | 运行九宫格用**懒创建**减 Context；以后再议共享 |
| 网格、装饰器、编辑插件 | **不采用** | 无 `Mesh` 端口本期；平面用线框/薄片 |
| Selection buffer 选 mesh | 不采用 | 只要点坐标状态栏 |

### 2.4 抄与不抄（汇总）

| 抄 | 不抄 |
|---|---|
| VBO + 抽点预算 + pivot 相机 | 嵌 CC / MeshLab / VTK 控件 |
| 云不变不重传；失败降级 | 完整图层文档 / 实体树 |
| 高度或 RGB 作 vertex color | 压缩法向库、复杂 shader |
| 平面 / 盒简单几何叠加 | 三角网格材质与纹理管线 |
| 右键切模式（本产品约定） | 浮动条、顶栏分段按钮 |

## 3. 架构

```text
HsImageCtrl.dll
│
├── HsViewShell                 ← 外层壳（对外主入口之一）
│     └── 内容区（stack / 显隐，无顶栏）
│           ├── HsImageWindow   ← 现有 2D，基本不动
│           └── HsCloudWindow   ← 新建，CC 式点云绘制
│     └── 右键：当前模式菜单 + 「图像 / 点云」切换
│
├── HsImageWindow / HsImageWindowMenu
├── HsCloudWindow
└── ImageWidgetApi              ← 组合 ViewShell；二维转发保持兼容
```

### 3.1 独立性

| | 2D | 3D |
|---|---|---|
| 坐标 | 像素 | 毫米，右手，Y 上 |
| 协议 | `HsImage`、`Graphic`、`HsObject` | `Cloud3`、`Shape3`、`Pose3` |
| 基类 | `QGraphicsView` | `QOpenGLWidget` |
| 交互 | ROI / 画笔 | 轨道球；无 `beginDrawSession` |

禁止：点云进 `Graphic`；业务自建切换条；`HsImageWindow` 内画点。

### 3.2 `HsViewShell`

| 职责 | 说明 |
|---|---|
| 布局 | 内容区铺满两子窗；**无**模式顶栏 / 浮动条 |
| 模式 | `ViewMode { Image2D, Cloud3D }`；`setViewMode`；`viewModeChanged` |
| 右键 | 统一弹出：2D 复用或迁入 `HsImageWindowMenu` 项 +「切换到点云」；3D 含「切换到图像」「复位视图」；无云时点云项灰显 |
| 访问 | `imageWindow()` / `cloudWindow()`（3D **懒创建**） |
| 状态 | 切换后各自视口保留 |
| 不负责 | 读文件、拟合、Job |

自动跟随结果：`setAutoFollowResult(bool)`，默认关；开则灌云后可切 3D。开始 2D ROI → 强制回 2D。

### 3.3 `ImageWidgetApi`

新建 `HsViewShell`，Api **组合**它：原换图 / 信息栏路径不变；三维 API 另开。九宫格可只嵌轻量 Shell。

## 4. `HsCloudWindow` 实现要点（按 CC 简化）

### 4.1 对外 API

| 调用 | 作用 |
|---|---|
| `setCloud(Cloud3)` | 底云；空则清；变则标记 VBO 脏 |
| `addCloud(name, Cloud3, Rgb8)` / `removeCloud` | 额外层（如内点绿） |
| `setShapes(...)` | 第一期至少 `Plane`（与包围盒相交多边形 + 法向短线） |
| `setPoses(...)` | 可二期；轴长取盒对角 8% |
| `setColorMode` | 高度 / 灰度 / RGB；非法退回高度 |
| `resetView` | 相机正对包围盒（中心 +Z，上 +Y） |
| 拾取 | 状态栏 xyz（mm）；不写端口 |

### 4.2 绘制与性能

1. `initializeGL`：探测上下文；失败则壳显示文案，2D 仍可用。  
2. 底云 / 额外层：交错或分缓冲上传 `xyz` + 颜色；**脏才上传**。  
3. 总绘制点（含额外层）> 约 150 万 → 按步长抽点进 GPU，CPU 侧 `Cloud3` 不动。  
4. 点大小约 2 px，深度测试开；形状后画。  
5. 角落叠加：总点数 / 本帧画出点数（可用 `QPainter` over GL）。

### 4.3 相机与键鼠

| 操作 | 行为 |
|---|---|
| 左键拖 | 绕 pivot 转；仰角夹紧，防翻顶 |
| 滚轮 | 沿视线缩放；近裁剪跟随 |
| 中键拖 | 平移 pivot |
| 双击 | `resetView` |
| 右键 | **只出菜单**（由壳处理），不拖相机 |

不链 PCL。不读 PLY。

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| 工控机 GL 差 / VBO 挂 | 探测失败有文案；VBO 失败退客户端数组（学 CC） |
| 九宫格 Context 多 | 3D 懒创建；禁用格不建窗 |
| 右键与 `HsImageWindowMenu` 打架 | 壳统一弹一次 |
| 用户不知可切 3D | 首次出云时状态栏提示一句；不加浮动条 |
| 百万点内存拷贝 | 与图像同样整份拷贝策略；样例控规模；共享缓冲以后与图像一起做 |

---

## 8. 分期验收

**第一期**

1. 右键可切图像 / 点云；无顶栏、无浮动条。  
2. 点云可转 / 滚轮 / 中键 / 双击复位；内点绿、平面可见；可抽点。  
3. 调试宿主嵌壳跑通拟合平面 ASCII PLY。  
4. 纯二维 ROI 与菜单回归通过；无 GL 时 2D 仍可用。

**第二期**：设计态 / 运行格统一壳；`setPoses`；可选 `autoFollow`。

**不做**：点云窗画三维 ROI；嵌 CC/ML；第一期网格显示。

## 10. 一句话

在 `HsImageCtrl` 做壳：右键切 2D/3D；图像窗不动；点云窗按 CloudCompare 简化自研 OpenGL 绘制，手感参考 MeshLab trackball。业务只嵌壳灌数，不引第三方三维控件。
